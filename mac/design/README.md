# design/

Погоджений дизайн застосунку, кадр за кадром. Це єдине джерело всього візуального.

- `Карта кадрів.md` — що є на полотні і що вирішує кожен кадр.
- `canvas/` — кадри полотна, по файлу `*.dc.html` на кадр, і `canvas.json` з розкладкою.
- `canvas/support.js` — рантайм, що малює кадр у браузері.

## Як відкрити кадр

Відкрити `canvas/<Кадр>.dc.html` у браузері. Рантайм бере React з unpkg, тому потрібен інтернет.

## Як оновлюється

Полотно редагується в claude.ai, а сюди копіюється цілком: усі файли `canvas/` і карта разом,
ніколи по одному.
